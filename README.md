# 🛍️ Flipkart Clone

A frontend **Flipkart-inspired e-commerce web app** built with **Vanilla HTML, CSS, and JavaScript** — featuring a product catalog across 8 categories, product detail pages, cart management, category browsing, and user authentication — all running client-side with no backend.

---

## ✨ Features

- 🏠 **Home Page** — Hero banner carousel, category grid, featured products with badges
- 📱 **Product Detail Page** — Images, specs, highlights, ratings, add-to-cart
- 🛒 **Shopping Cart** — Add/remove items, quantity control, price summary
- 🔍 **Category Pages** — Filter products by category
- 🔐 **Auth Page** — Login / Register UI
- 🏷️ **32 Products** across 8 categories with real-world pricing (in ₹)
- 📸 **Dynamic Images** — All product images loaded from Picsum Photos CDN

## 🚀 Getting Started

No build step needed! Just open in a browser:

```bash
git clone https://github.com/ojasvcode/flipkart-clone.git
cd flipkart-clone
open index.html
```

Or serve locally:
```bash
npx serve .
```
